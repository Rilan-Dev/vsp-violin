What this needs to work for real

A login, a database of lessons and categories, and file storage for the PDFs and audio. Menus and pages then build themselves from that data. It is a well-trodden build — but it is a second phase beyond the frontend, and it carries a small monthly hosting cost.

Cheaper alternative, if you prefer: the categories stay in one editable file and you send me new lessons to add. Slower for you, no running cost. Tell me which you want and I will plan around it.
